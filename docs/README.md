# Reference & handoff docs

This folder is the **knowledge base** behind the site — the research and source material we worked
from, kept here so it's easy to refer back to even when a given detail isn't surfaced on the public
pages. It's for planning and continuation, not for the build (nothing here is published as a page;
Astro only renders `src/pages` + `src/content`).

## Contents

| File | What it is |
|------|-----------|
| [`status-and-roadmap.md`](status-and-roadmap.md) | **Start here.** What's done so far, the decisions that are locked, and the next steps. The handoff. |
| [`engineering-philosophy.md`](engineering-philosophy.md) | The full engineering philosophy, first person. The soul of the site's voice. |
| [`master-narrative.md`](master-narrative.md) | The career narrative / reservoir: thesis, trajectory, personas, project inventory, skills. |
| [`case-studies.md`](case-studies.md) | Detailed writeups of the work — including projects not (yet) on the site. |

## ⚠️ This is a PUBLIC repository

`kevinamitshah.github.io` is public (GitHub Pages user sites have to be). Anything committed here is
world-readable and indexable. So this knowledge base is deliberately limited to **public-safe**
content:

- The launch client stays **anonymized** (as on the résumé).
- **No team-level business metrics** of aiRA are claimed as individual work.
- Shared-ownership work is labelled honestly ("with tech lead / senior engineer").
- **Interview-only material is intentionally excluded** — specifically the production-incident
  details from the Journey Canvas launch (the org limit that was hit and the points issue that was
  caught and fixed). Those live only in the local master narrative
  (`~/Documents/gigs/portfolio/master_narrative.md`), not here.

If you ever want the unabridged version tracked in version control, put it in a **private** repo,
not this one.
