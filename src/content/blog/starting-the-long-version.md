I'm 23, and this is the first version of a site I intend to keep for a long time.

The plan isn't to launch it finished. It's to start it honest and let it accrete — case studies as I ship things worth writing up, notes as I learn things worth keeping. A portfolio that's "done" is a portfolio that's dead.

There are two things I want it to resist. The first is sounding like a résumé — a list of technologies and adjectives. I'd rather show the reasoning behind a few real decisions than claim a stack. The second is sounding like nobody wrote it. The voice here is mine: first person, occasionally uncertain, because the alternative reads like everyone else's.

So — more soon, and slowly. If you're reading this early, you're reading the foundation.
